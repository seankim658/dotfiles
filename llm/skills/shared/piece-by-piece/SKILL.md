---
name: piece-by-piece
description: Work through an agreed plan incrementally instead of building it all at once. Use when starting implementation after a plan has been reviewed, or when the user wants to build and review one step at a time. Do not use when the user has asked for a complete implementation in a single pass.
---

Build the agreed plan in small pieces so I can review and ask questions before too much exists.

Start by splitting the plan into ordered pieces. Each piece should be small enough to review in one sitting and should leave the code in a working state. Show me the breakdown briefly, then build only the first piece.

After each piece, stop and wait for me. Don't start the next piece, and don't stub out later pieces unless the current one needs them to work. Deliver each piece the way the active response skill describes, either in-chat or in-patch.

If a piece shows the plan is wrong, stop and say so instead of working around it.
